# ESP32 サウナ自律ロガー 購入・加工リスト

調査日: 2026-07-14

## 結論

初号機は、PCをサウナ室へ持ち込まない自律記録型とする。室外で電源ボタンを押し、青色照光と状態LEDを確認して蓋を閉め、保冷ケースをサウナ室の床付近へ運ぶ。計測中はmicroSDへ保存し、回収・常温復帰後にケースを開けてUSB接続する。

購入方針は次のとおり。

- 電子部品、センサー、電源、microSDは新品を買う。
- 穴あけする保冷ケース、三脚・ポール、ドリル、一般工具は中古でよい。
- ブレッドボードは机上試験だけに使う。サウナ投入時はユニバーサル基板へはんだ付けする。
- USBパネル端子と液晶は初号機には付けない。穴と結露経路を減らす。
- 汎用Li-ionモバイルバッテリーは使わず、単3形Ni-MH電池を交換できる電源を使う。

## 4. 穴あけと内部配置

ケースへ穴を開ける前に、現物を並べて次の配置に固定する。

```text
上面/側面（外から操作・確認）
  [青色POWERボタン] [緑RUN LED] [赤FAULT LED]

ケース内
  ┌──────────────────────────────┐
  │ 電子室                              │
  │ ESP32 ─ microSD ─ MAX31855          │
  │   └ DS18B20（基板近傍の空気温度）   │
  │                                    │
  │ EVA/PE仕切り＋吸水シート            │
  │                                    │
  │ 冷却室: PP密閉容器＋保冷剤×2        │
  └──────────────────────────────┘
       PG7 → SHT45 / K熱電対
```

加工順は、マスキングテープに穴中心を記入、下穴3 mm、ステップドリルで拡大、面取り、部品を仮組み、最後に補助シールとする。スイッチ穴径とPG7取付穴径は呼称だけで決めず、届いた部品の寸法図と実測値を使う。

外に出すSHT45の4芯ケーブルは、センサー基板のすぐ横で継がず、引張荷重が基板へ掛からないようストレインリリーフを作る。K熱電対線を普通の銅線で延長しない。

## 5. 運用上の安全条件

- ケースは床付近、ヒーター・ストーブ・給気口・ロウリュ水の飛沫から離して置く。
- 電子室と冷却室を仕切り、保冷剤はPP容器とジップ袋で二重にする。
- ケース内温度40℃で赤LED警告、45℃で記録を終了して安全停止する。
- サウナ室内では充電しない。膨張、漏液、異臭、電池の発熱があれば使用しない。
- BQ-CC87には出力自動停止機能があるため、完成後は室温で2時間以上連続記録し、途中でUSB出力が止まらないことを実機確認する。
- 回収直後に蓋を開けたりUSB接続したりしない。外面の水分を拭き、常温へ戻してから開ける。
- IP67/IP68部品を使っても、加工後のケース全体が同じ防水等級になるわけではない。投入前に空ケースで霧吹き試験と結露試験を行う。
- 人が利用中のサウナで無人放置しない。施設管理者の許可を取り、転倒・接触・避難動線を妨げない。

- 中古または無名のLi-ionモバイルバッテリー
- サウナ投入用ブレッドボード、Dupontジャンパ線
- 液晶ディスプレイ、タッチパネル
- パネルUSB延長端子
- ソフトクーラー、発泡スチロール箱
- DHT11/DHT22
- 4チャネル熱電対ロガー（初号機では1チャネルで足りる）
