# ESP32 サウナ自律ロガー 購入・加工リスト

調査日: 2026-07-17

## 結論

初号機は、PCをサウナ室へ持ち込まない自律記録型とする。室外で電源ボタンを押し、青色照光と状態LEDを確認して蓋を閉め、保冷ケースをサウナ室の床付近へ運ぶ。計測中はmicroSDへ保存し、回収・常温復帰後にケースを開けてUSB接続する。

購入方針は次のとおり。

- 電子部品、センサー、電源、microSDは新品を買う。
- 穴あけする保冷ケース、三脚・ポール、ドリル、一般工具は中古でよい。
- ブレッドボードは机上試験だけに使う。サウナ投入時はユニバーサル基板へはんだ付けする。
- USBパネル端子と液晶は初号機には付けない。穴と結露経路を減らす。
- 電源は保護回路内蔵LiPoを優先する。専用充電・5 V昇圧基板、電池表面温度監視、40℃ハード遮断を必須とし、条件を満たせない場合だけeneloopへ切り替える。

## LiPo電源（優先案）

LiPoを使うことは可能だが、次の3点を必ず1組で使う。

| 部品 | 型番・URL | 数量 | 役割 |
|---|---|---:|---|
| 保護回路内蔵LiPo | [3.7 V 2000 mAh、63-3112-79 / X366280](https://www.askul.co.jp/p/X366280/) | 1 | 電池。PHR-2コネクタ、保護回路内蔵 |
| 専用充電＋昇圧基板 | [SFE-PRT-14411、SSCI 3505](https://www.switch-science.com/products/3505) | 1 | LiPoを充電し、ESP32用5 V/1 Aへ昇圧 |
| 充電コード | [USB A-microB、秋月107607](https://akizukidenshi.com/catalog/g/g107607/) | 1 | 室外・常温での充電。ESP32書込み用と兼用可 |

配線は `LiPo → JST-PH → 3505基板 → 5 V/GND → ESP32の5V/GND` とする。LiPoをESP32の5 V端子へ直接つながない。異なるメーカー間ではJST-PHの極性が逆の場合があるため、初接続前にマルチメーターで赤線側がプラスであることを確認する。

3505基板は保護回路内蔵電池専用であり、充電中は負荷を20 mA以下にする必要がある。したがってESP32の主電源をOFFにし、ケースをサウナ室外へ出して蓋を開けた状態でのみ充電する。充電を無人で行わない。

LiPoの一般的な温度範囲は充電0～45℃、放電-20～60℃である。サウナ用途では上限ぎりぎりまで使わず、DS18B20のプローブを電池表面へ固定し、次の制御値とする。

- 30℃: ケース冷却状態を確認する予告表示
- 35℃: 赤LED警告、計測終了処理を開始
- 40℃: 電源を強制遮断

ソフトウェア停止だけでなく、[Sensata 67L040（40℃、常閉、温度上昇時に開く）](https://www.digikey.jp/ja/products/detail/sensata-airpax/67L040/5082088)をLiPo出力と直列に追加する。2026-07-17確認時はDigiKey通常在庫0個、マーケットプレイス在庫のみなのでカート未投入である。電池は保冷剤と直接接触させず、薄い緩衝材で圧迫・穿刺から保護し、電子基板より上に置かない。

LiPo電源一式は4,917円＋4,048円＋170円で **9,135円＋送料**。eneloop案より高価だが、ユーザー希望に合わせて初号機の優先案とする。eneloop K-KJ87MCD40Lは、LiPoが入荷しない場合または温度遮断試験を通らない場合の予備案とする。

## 4. 穴あけと内部配置

ケースへ穴を開ける前に、現物を並べて次の配置に固定する。

```text
上面/側面（外から操作・確認）
  [青色POWERボタン] [緑RUN LED] [赤FAULT LED]

ケース内
  ┌──────────────────────────────┐
  │ 電子室                              │
  │ ESP32 ─ microSD ─ MAX31855          │
  │   └ DS18B20（基板近傍の空気温度）   │
  │                                    │
  │ EVA/PE仕切り＋吸水シート            │
  │                                    │
  │ 冷却室: PP密閉容器＋保冷剤×2        │
  └──────────────────────────────┘
       PG7 → SHT45 / K熱電対
```

加工順は、マスキングテープに穴中心を記入、下穴3 mm、ステップドリルで拡大、面取り、部品を仮組み、最後に補助シールとする。スイッチ穴径とPG7取付穴径は呼称だけで決めず、届いた部品の寸法図と実測値を使う。

外に出すSHT45の4芯ケーブルは、センサー基板のすぐ横で継がず、引張荷重が基板へ掛からないようストレインリリーフを作る。K熱電対線を普通の銅線で延長しない。

## 5. 運用上の安全条件

- ケースは床付近、ヒーター・ストーブ・給気口・ロウリュ水の飛沫から離して置く。
- 電子室と冷却室を仕切り、保冷剤はPP容器とジップ袋で二重にする。
- eneloop使用時はケース内40℃で赤LED警告、45℃で記録を終了する。LiPo使用時は35℃警告・終了処理、40℃強制遮断とする。
- サウナ室内では充電しない。膨張、漏液、異臭、電池の発熱があれば使用しない。
- BQ-CC87には出力自動停止機能があるため、完成後は室温で2時間以上連続記録し、途中でUSB出力が止まらないことを実機確認する。
- 回収直後に蓋を開けたりUSB接続したりしない。外面の水分を拭き、常温へ戻してから開ける。
- IP67/IP68部品を使っても、加工後のケース全体が同じ防水等級になるわけではない。投入前に空ケースで霧吹き試験と結露試験を行う。
- 人が利用中のサウナで無人放置しない。施設管理者の許可を取り、転倒・接触・避難動線を妨げない。

## 6. 買わないもの

- 中古または無名のLi-ionモバイルバッテリー
- サウナ投入用ブレッドボード、Dupontジャンパ線
- 液晶ディスプレイ、タッチパネル
- パネルUSB延長端子
- ソフトクーラー、発泡スチロール箱
- DHT11/DHT22
- 4チャネル熱電対ロガー（初号機では1チャネルで足りる）
